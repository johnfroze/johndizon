2D/3D Lottery Betting Management System

A full-featured betting operations platform for Philippine STL lottery coordinators. Handles real-time bet validation, multi-agent billing, pool-limit enforcement, win computation, and financial reporting — all in a single self-contained HTML file with a Supabase backend.

  • Real-time input parser with auto-detection of 2D vs 3D bets, Pompi, Petsada, Trio, and Double-R special categories
  • First-come-first-served max bet pool engine with partial void support per combination+type
  • Per-agent billing: commission, gross, remit, win payout, and receipt tracking with image export
  • Void Center with manual void tab, agent search filter, and auto-hide after copy
  • Win Tab with result matching, prize calculation, and combine-winners toggle
  • Admin panel: account management, expiry control, session enforcement (single-device login)
  • Hub page with module navigation — 2D/3D System + Bet Summarizer
  • Bet Summarizer: combine & auto-sum bets from file upload or paste, 2D/3D/Pompi/Petsada columns with error column
  • Role-based authentication with Supabase, session tokens, and keep-alive pinging

02
TOOL
Bet Summarizer (Dikit Combi & Auto-Sum)

A standalone data-processing tool that replicates and extends a VBA Excel macro in the browser. Agents paste raw bet data and the tool instantly combines duplicates, normalizes ramble orders, separates Pompi/Petsada, and flags format errors — with file upload and drag-and-drop support.

  • Disambiguates 2D vs 3D lines using column count + type-position heuristics
  • Normalizes number formats (01 and 1 treated as identical)
  • Auto-corrects Pompi and Trio bets from Ramble to Straight
  • Validates amount as multiples of 5, number ranges, and type values
  • File upload (.txt) and drag-and-drop onto textarea
  • One-click copy per column with optional type column inclusion
